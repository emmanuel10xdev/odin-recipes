# odin-recipes
This project marks the completion of my HTML foundations. 
It demonstrates my ability to structure web pages using semantic HTML elements including headings, paragraphs, links, images and lists without relying on AI assistance or tutorials during the building process.
Completing this project shows that I can create a properly structured HTML document from a blank file, understand how elements relate to each other and apply best practices like semantic markup and proper document structure.
This wasn't just a technical exercise, it represents a genuine shift from someone who couldn't build anything independently to someone who understands the foundation of every website on the internet.
